# HARI KESHAV S M — Portfolio

Cinematic 3D Interactive Portfolio of **Hari Keshav S M** — AI & Web Developer | Visual Artist.

## Features
- **3D Cinematic HK Intro**: Built with Three.js WebGL, scattered metallic fragment assembly, magnetic force fields, Mjölnir-style attraction, metallic impact effects, and hyperspace warp speed camera transition.
- **Synthesized Sci-Fi SFX**: Real-time Web Audio API sound synthesis.
- **Interactive Portfolio Sections**: AI & Web Engineering projects, visual artist gallery, custom cursor, and responsive dark sci-fi design system.

## Tech Stack
- React 19 + Vite
- Three.js WebGL
- Framer Motion & Tailwind CSS
- Lucide React
